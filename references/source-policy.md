# Source Policy

Use this skill only for ValueGe / 价值&投资 public Longbridge material.

Primary source:

- Longbridge profile ID `3090`
- Longbridge profile URL: `https://longbridge.com/zh-CN/profiles/3090`
- Public API base used by the bundled fetcher: `https://m.lbkrs.com/api/forward`

Do not present private trading records as available. The profile page reports trade record authorization as unavailable, so only public posts, public stock-view data, and public topic details are valid evidence.

Evidence levels:

- `A`: Explicit self-operation language, such as bought, sold, added, trimmed, cleared, built a position, sold put, or bought call.
- `B`: Stated holding status, such as core holding, common shares, long hold, non-sellable, or not moving a position.
- `C`: Intent, watchlist, thesis, wait-for-opportunity, or planning language.
- `D`: External information, such as another investor's filing, company news, earnings, or market data without a clear self-operation.
- `U`: Unclassified, personal, lifestyle, or ambiguous content.

When answering:

- Separate explicit operations from opinions.
- Include topic links for every concrete claim.
- Use "公开帖子显示" or "他公开表达" instead of implying verified brokerage records.
- Treat evidence levels and symbol matching as machine-assisted triage. Multi-symbol posts require reading the full text before saying a specific symbol was bought, sold, or held.
- Avoid investment advice. Summarize historical behavior and stated reasoning.
- Prefer paraphrase and short excerpts. Do not paste long post text unless the user specifically asks for a source excerpt.
